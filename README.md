# Total Commander Addons

> Репозиторий готовых аддонов для **Total Commander**, сформированных в **TCPU Addon Maker**.

Здесь публикуются скомпилированные дополнения, предназначенные для быстрой установки и использования в Total Commander.

---

## Установка

1. Скачайте нужный аддон.
2. Откройте его в Total Commander.
3. Подтвердите установку.
4. При необходимости перезапустите Total Commander.

## AsSys

- **Файл:** `AsSys.exe`
- **Версия:** `1.0.1.0`
- **Автор:** FreeTm (FreeTm@my.com)

Утилита для перезапуска Total Commander под разными контекстами безопасности:

- `-u` / `/u` — текущий пользователь (USER)
- `-a` / `/a` — с правами администратора (ADMIN, через UAC)
- `-s` / `/s` — от имени `NT AUTHORITY\SYSTEM` (SYSTEM, через дублирование системного токена)

**Состав:**

- `AsSys.au3` — исходник на AutoIt
- `AsSys.exe`, `AsSys_x64.exe` — скомпилированные AutoIt-версии
- `AsSys_Laz\AsSys.lpr` — исходник на Free Pascal / Lazarus
- `AsSys_Laz\AsSys_laz.exe` — скомпилированная Lazarus-версия
- `icon\A.ico`, `icon\S.ico`, `icon\U.ico` — иконки режимов

**Использование:**

Запуск из командной строки или кнопки Total Commander:

```
AsSys.exe -u "C:\TCPU75\TOTALCMD64.EXE"
AsSys.exe -a "C:\TCPU75\TOTALCMD64.EXE"
AsSys.exe -s "C:\TCPU75\TOTALCMD64.EXE"
```

Путь к Total Commander можно передавать явно; если запуск идёт из самого TC, программа пытается определить путь через родительский процесс.

**Особенности:**

- Работает без внешнего `ras.exe`.
- Режим SYSTEM использует нативные Windows API: поиск системного процесса, дублирование токена и `CreateProcessWithTokenW`.
- При ошибках SYSTEM выводится код Windows-ошибки.
- Антивирусы/EDR могут реагировать на операции с токенами SYSTEM; это нормальное поведение, которое нельзя гарантированно убрать.

## cftc

- **Файл:** `cftc.exe`

Утилита быстрого создания нового файла.

**Особенности:**

1. Работает через параметры `%P%N`. ⚠️ Без параметров создаёт файл возле себя!
2. Можно самому назначать расширения — изменяем блокнотом файл `.ext` рядом с программой (защиты на дурака здесь и не планировалась).
3. Добавлен фильтр запрещённых символов — не позволяет вставить запрещённые ОС символы.
4. Добавлены быстрые клавиши для удобства:
   - `F1` — вставить дату (теперь можно отменить)
   - `F2` — исключить название файла (например `.txt`)
   - `F3` — открыть после создания (требует доработки)
   - `F4` — выбор расширения (если вдруг нет мышки)
   - `Enter` — применить и закрыть
   - `Esc` — просто закрыть

**Примечания:**

- Если будет ругаться антивирус, то это 100% из-за упаковщика!
- ⚠️ Если файл существует, программа просто пересоздаст его пустым!

## FCleaner

- **Файл:** `FCleaner.exe`

FluentCleaner Classic (FCleaner) — portable-очиститель Windows в духе CCleaner: правила Winapp2/Winapp3, анализ, выбор и удаление кэшей, temp-файлов и связанных записей реестра.

**Возможности:**

1. Анализ и очистка по встроенным базам `Winapp2.ini` / `Winapp3.ini` (тысячи правил для Windows и программ).
2. Свои правила (`Custom\`), исключения, история, планировщик, post-clean команды, опциональные AI-пояснения.

**В этой сборке:**

1. .NET Framework 4.8, движок `FluentCleaner.Core.dll`.
2. Локализации: +русский, +украинский, +белорусский.
3. Кастомные правила для учётного ПО: 1С, СБИС, Контур и др.

## GeekUninstaller

- **Файл:** `GeekUninstaller.exe`

Geek Uninstaller — лёгкий инструмент для удаления программ в Windows.

**Возможности:**

- **Глубокое сканирование.** После того как штатный деинсталлятор программы отработает, Geek Uninstaller проверяет систему и предлагает удалить найденные остатки — файлы, папки, записи в реестре.
- **Принудительное удаление (Force Removal).** Выручает, когда программа «застряла»: её собственный деинсталлятор не срабатывает, повреждён или блокирует удаление. Утилита самостоятельно стирает файлы и чистит реестр.
- **Дополнительные инструменты.** Через контекстное меню можно открыть папку установки программы, посмотреть её запись в редакторе реестра, поискать информацию о ней в интернете.
- **Экспорт списка** установленного ПО в HTML-файл.

## MemCleaner

- **Файл:** `MemCleaner.exe`

Утилита очистки оперативной памяти.

**Что делает:**

1. Уменьшает рабочие наборы процессов (`EmptyWorkingSet`).
2. Очищает standby-списки физической памяти.
3. Сбрасывает системный файловый кеш.
4. Уведомляет о своей работе (всплывающее окно).
5. Запускается с правами администратора (UAC-манифест встроен).

**Параметры командной строки** (пишутся с `-` или `/`, регистр не важен):

| Параметр | Действие |
|----------|----------|
| `/clean` | Разовая очистка: запуск → очистка → всплывающее уведомление → автоматический выход |
| `/install` | Добавить в автозагрузку (задача Планировщика) и выйти |
| `/uninstall` | Удалить из автозагрузки и выйти |
| `-a<N>` | Включить автозагрузку и установить интервал очистки в N минут; программа остаётся в трее. Максимальный интервал — 120 мин. В задачу записывается команда `"путь\MemCleaner.exe" -a120`, так что после перезагрузки интервал сохранится |
| *(без параметров)* | Постоянная работа в трее с очисткой по таймеру |

## NTFSAccess

- **Файл:** `NTFSAccess.exe`

Эта утилита позволяет легко стать владельцем папки! Она будет особенно полезна тем, кто не очень хорошо разбирается в компьютерах, а также в случаях, когда необходимо удалить папку, созданную какой-либо программой, или папку, которая является системной.

## Nyx

- **Файл:** `Nyx.exe`

Nyx — автономный скрипт удаления следов работы.

**Что умеет удалять:**

1. Журналы событий (безопасность, система, приложения, Sysmon, WinRM, PowerShell/операционные системы, AppLocker, AMSI)
2. История PowerShell/CMD, предварительная загрузка, списки переходов, последние документы, временная шкала Windows, история поиска, история IE/Edge
3. MRU в реестре, история USB-накопителей, BAM/DAM, ShellBags, UserAssist, клиент терминального сервера, медиаплеер, MRU в Office
4. Журнал USN, корзина, кэш изображений, ярлыки, индексные файлы, база данных SRUM, история уведомлений
5. Временные файлы, кэш DNS, теневые копии, архивы WER, аварийные дампы, история Кортаны, телеметрия Office, журналы OneDrive/Teams
6. Журналы EDR/AV (CrowdStrike Falcon, SentinelOne, Carbon Black, McAfee, Symantec), журналы ATP Защитника Windows, журналы брандмауэра, активность WMI, ключи BitLocker, кэш групповой политики, кэш аутентификации, журналы Hyper-V/WSL/Docker, артефакты FTK Imager
7. Сертификаты, запланированные задачи, службы, профили беспроводной сети, VPN-подключения, расширения Chrome, криптографические данные, журналы TPM, журналы Центра обновления Windows, push-уведомления, поиск в Outlook, журналы WSA, игровая панель Xbox

## SnakeTail

- **Файл:** `SnakeTail.exe`

SnakeTail — мониторинг логов в реальном времени.

**Особенности:**

1. Возможность работать с сессиями (сохранять и возобновлять через `*.xml`).
2. Умеет выставлять открытые файлы в отдельные окна (с сохранением положений и размеров окон, через сессии `*.xml`).
3. Работает не только с файлами логов.

## SwiftSearch

- **Файл:** `SwiftSearch.exe`

SwiftSearch — лёгкая утилита, которая моментально находит файлы без фоновых процессов.

**Особенности:**

1. Умеет искать на основе пути (например, `*Program*Windows*`).
2. Ищет файлы напрямую, без предварительной подготовки.
3. Только NTFS, требует прав администратора.
4. Частично руссифицирован (через `*.mui`).

## Unlock

- **Файл:** `Unlock.exe`

Unlock — модификация файла `ThisIsMyFile.exe` для разблокировки, удаления папок/файлов, занятых процессом или имеющих некорректное имя.

Формально это тот же ThisIsMyFile, но с удалёнными ненужными элементами GUI.

## xdpl

- **Файл:** `xdpl.exe`

xdpl — xdelta patcher. Утилита, которая создаёт дельту изменений оригинала и патченного файла, которую впоследствии можно применить на оригинале после обновлений.
